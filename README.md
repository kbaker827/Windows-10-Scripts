# Windows-10-Scripts

Scripts for Windows 10 administration and management.

## Contents

### Metered Connection

`Metered Connection/Manage-MeteredConnection.ps1` - Toggle WiFi adapter metered connection state. Useful for controlling Windows Update bandwidth usage on metered connections.

## Usage

Run scripts in an elevated PowerShell session:

```powershell
# Manage metered connection
.\ "Metered Connection\Manage-MeteredConnection.ps1"
```
